Data Input Array Byte RGB Piksel Gambar (Red, Green, Blue)
Langkah Pemrosesan AES-128:
  1. Key Expansion: Menghasilkan 11 Round Keys (176 byte) dari kunci utama via S-Box & Rcon.
  2. Ekstraksi RGB: Membagi byte RGB gambar ke dalam blok berukuran 16 byte.
  3. Initial Round: Operasi AddRoundKey (XOR byte blok dengan Round Key ke-0).
  4. Round 1–9: Transformasi SubBytes, ShiftRows, MixColumns, dan AddRoundKey.
  5. Final Round (10): SubBytes, ShiftRows, dan AddRoundKey (tanpa MixColumns).
  6. Rekonstruksi Canvas: Menyusun kembali byte hasil ke kanvas gambar dengan kanal Alpha = 255.
